# Milestone Roadmap: v0.2.0

## Phase 1: Core Audio Ingestion & Normalization
- [x] FFmpeg 16kHz mono resampling & multi-format loader.
- [x] YouTube (`yt-dlp`) & Google Drive (`gdown`) downloader.
- [x] Persistent upload cache in `data/uploads/`.

## Phase 2: Speech Recognition & Speaker Diarization
- [x] Faster-Whisper ASR with CTranslate2 GPU/CPU support.
- [x] PyAnnote 3.1 neural speaker diarization.
- [x] Temporal intersection alignment engine.

## Phase 3: Multi-Model Persistence & Benchmark Engine
- [x] SQLite WAL database (`data/history.db`) with compound indexes.
- [x] SequenceMatcher normalized word diffing (additions, deletions, substitutions).
- [x] Benchmark summary metrics (Similarity %, Speed ratio, Words delta, Speakers).
- [x] 1-click model runner quick chips.

## Phase 4: Delivery & UI
- [x] Real-time SSE streaming server.
- [x] Zero-latency client cache with Stale-While-Revalidate.
- [x] Multi-format exporters (Markdown, SRT, VTT, TXT, JSON).
- [x] CLI (`transcribe`) and REST API.

## Phase 5: Verification & Quality Gate
- [x] Full automated test suite (14/14 tests passing).
- [x] Live SSE test on sample audio verified.
